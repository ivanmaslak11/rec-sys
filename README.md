# Домашнее задание 1 — рекомендательные системы

Маслак Иван Александрович

Датасет: Amazon Product Data (2014), Video Games, 5-core.
[Первоисточник — Julian McAuley, UCSD](https://mcauleylab.ucsd.edu/public_datasets/data/amazon/datasets.html).

Основная работа — [experiments.ipynb](experiments.ipynb): загрузка данных, EDA, временное разбиение,
пять моделей, подбор параметров, результаты и выводы. Реализации моделей находятся в `models/`.

Для запуска установите зависимости командой `python -m pip install -r requirements.txt`,
откройте ноутбук в VS Code или Jupyter и выполните Restart & Run All.
Python 3.9–3.12. Подробные инструкции приведены в начале ноутбука.
Данные скачиваются ячейкой загрузки в `data/` и исключены из Git.
